# FinanceApp

Personal finance dashboard for Android — a **Next.js 14 app wrapped in a Capacitor
native shell**.

| | |
|---|---|
| Package | `com.financeapp` |
| App name | `FinanceApp` (display title: *Fintech App*) |
| APK | 9.6 MB, versionCode 1 / versionName 1.0.0 |
| Android | minSdk 24, targetSdk 36, compileSdk 36 |
| Web runtime | Next.js 14.2.35 (App Router, static export) + React 18.3.1 |
| UI | Tailwind CSS 3.4.19, Recharts, Lucide React |
| Native bridge | Capacitor (`@capacitor/camera`, `@capacitor/local-notifications`) |

> **This repository is a reconstruction.** The original project was recovered from a
> compiled `FinanceApp.apk`, not from its source tree. Application logic is faithful
> to the shipped JavaScript bundle, but this is **not** the original TypeScript/JSX.
> Read **[RECOVERY.md](RECOVERY.md)** before treating any of it as canonical.

## What the app does

A single-screen, mobile-first finance dashboard with a bottom tab bar. All data is
**hardcoded mock data** in the client bundle — there is no backend, no auth, and no
persistence. It is a UI prototype.

Screens, all in `src/app/page.jsx`:

| Component | Purpose |
|---|---|
| `App` | Root shell. Owns dark mode, toast, modal, and navigation state. |
| `Dashboard` | Net worth area chart, spending-by-category pie, account selector, recent transactions. |
| `Spaces` | Virtual envelopes/savings pots; move money between spaces. |
| `Invoices` | Invoice list and detail (`IN-001`), issue/due dates, line items, auto-reminder. |
| `Receipts` | Receipt capture and filing — uses the **Capacitor camera** plugin. |
| `Analytics` | Income vs. expenses bar chart, totals, savings rate. |
| `Budgets` | Per-category budgets with spent/remaining. |
| `Subscriptions` | Recurring services (Netflix, Spotify, ChatGPT Plus, Amazon Prime). |
| `TabBar` | Bottom navigation: dashboard / spaces / invoice + quick-add. |
| `Sheet`, `Toast`, `Pressable`, `Screen` | Shared UI primitives. |

Native device integration is limited to two plugins, both confirmed in
`android-decompiled/resources/assets/capacitor.plugins.json`:

- **Camera** — `Camera.getPhoto()` for receipt capture, base64 result.
- **Local notifications** — permission request and scheduled reminders (budget/bill alerts).

## Repository layout

```
src/app/page.jsx        Reconstructed application source (5,788 lines, 14 components)
src/app/layout.jsx      Root layout + metadata
src/app/globals.css     Tailwind directives + the app's two custom CSS rules
out/                    EXACT web assets extracted from the APK (byte-for-byte)
recovered/bundles/      The same JS chunks, pretty-printed and readable
android-decompiled/     jadx output: com.financeapp, Capacitor bridge + both plugins,
                        decoded AndroidManifest.xml and resources
tools/de-minify.py      The bundle -> source transform
tools/recover.sh        End-to-end recovery pipeline, re-runnable on any APK
```

`out/` and `android-decompiled/` are the ground truth. `src/` is derived from them.

## Running it

```bash
npm install
npm run dev            # Next.js dev server
npm run build          # static export -> out/
npx cap sync           # copy out/ into the Android project
```

`out/index.html` also runs standalone in any browser — the bundle is a static export
with no server dependency.

## Rebuilding the Android app

The Gradle project itself is **not** included; a Capacitor Android project is
scaffolder boilerplate and is regenerated by `npx cap add android`. What *was* in the
APK and could not be regenerated is preserved under `android-decompiled/`:

```bash
# the app's only native class
cat android-decompiled/sources/com/financeapp/MainActivity.java

# manifest, including the permission set
cat android-decompiled/resources/AndroidManifest.xml
```

## Re-running the recovery

```bash
./tools/recover.sh /path/to/FinanceApp.apk
```

Extracts, pretty-prints, decompiles with jadx, and regenerates `src/app/page.jsx`.
